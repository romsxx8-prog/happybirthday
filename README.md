# 🎂 کیک تولد سه‌بعدی تعاملی - نسخه ۱۶ سالگی

یک کیک تولد سه‌بعدی شاد و تعاملی ساخته‌شده با Three.js که به صورت کامل به زبان فارسی شخصی‌سازی شده است.

## ویژگی‌ها

- **شمع‌های عددی طلایی براق و واقعی «۱» و «۶»** دقیقاً شبیه عکس شمع‌های طلایی (فلزی، براق، با پایه چوبی و شعله واقعی) — عدد ۱۶ کامل برای فوت کردن
- چرخش نرم و زیبای کیک
- خاموش کردن شمع‌ها با فوت کردن داخل میکروفون یا نگه داشتن انگشت روی موبایل
- افکت‌های قلب صورتی و کنفتی رنگی **فقط بعد از خاموش شدن کامل شمع‌ها**
- پخش خودکار صدای cheer/هورا پس از خاموش شدن
- فضای روشن، گرم و جشن‌گونه (نورپردازی طلایی و صورتی)
- تزئینات خامه و توت‌فرنگی روی کیک
- امکان تعویض آهنگ دلخواه (فایل mp3)
- ۱۰۰٪ فارسی و ریسپانسیو

## نحوه اجرا

1. فایل ZIP را دانلود و extract کنید.
2. وارد پوشه پروژه شوید:
   ```bash
   cd persian-birthday-cake
   ```
3. وابستگی‌ها را نصب کنید:
   ```bash
   npm install
   ```
4. پروژه را اجرا کنید:
   ```bash
   npm run dev
   ```
5. مرورگر را باز کنید (معمولاً http://localhost:5173).

برای ساخت نسخه نهایی:
```bash
npm run build
```

## فایل‌های صوتی

- `happy-birthday.mp3` : آهنگ تولد (قابل تعویض با هر فایل mp3 دلخواه شما)
- `cheer.mp3` : صدای هورا/دست‌زدن

برای تعویض آهنگ، فقط فایل `happy-birthday.mp3` را با فایل دلخواه خود جایگزین کنید.

## نکات استفاده

- حجم صدا را بالا ببرید.
- روی دسکتاپ: داخل میکروفون فوت کنید.
- روی موبایل: انگشت را روی صفحه نگه دارید.
- بعد از اتمام آهنگ، شمع‌های عدد ۱۶ را خاموش کنید تا افکت‌های جشن شروع شود.
